Azure Linux Test Page

This page confirms that the web server is able to serve content.

If you are visiting this website

The website may not have been configured yet or may be undergoing maintenance. Contact the website administrator if you expected different content.

Microsoft does not administer this website simply because it uses Azure Linux.

If you are the website administrator

Configure your web server and deploy your website content to replace this default page.

For nginx, the default document root is /usr/share/nginx/html. For Apache HTTP Server, it is /var/www/html; the fallback welcome page is configured in /etc/httpd/conf.d/welcome.conf.

For information about the operating system, see the Azure Linux project.

# Haskell (GHC/Cabal) idioms

Source: [Fedora Haskell Packaging Guidelines](https://docs.fedoraproject.org/en-US/packaging-guidelines/Haskell/).
Local provider: [ghc-rpm-macros](../../../../specs/g/ghc-rpm-macros/) (`macros.ghc`, `ghc-deps.sh`, `cabal-tweak-*`).
Specs are generated by `cabal-rpm` (header comment); Fedora updates Haskell as coordinated Stackage-LTS stacks.

## How dependencies work (the reason overlays are dangerous here)

- `ghc-deps.sh` generates `-devel`/`-prof` Requires/Provides keyed by the **package id including an ABI hash**
  (e.g. `ghc-devel(hashable-1.4.7.0-<hash>)`). Any rebuild that changes the ABI (version bump, different Cabal
  flags, different dependency versions) changes the hash.
- So changing one library requires **rebuilding every reverse dependency** (transitively) in the same batch, or
  their installed `-devel` packages become uninstallable. Find them:
  `grep -lE 'ghc-<pkg>-(devel|prof)' specs/g/ghc-*/*.spec` and repeat for each result.
- Haskell PVP: `A.B` is the major version. Bumping `A.B` (1.4 → 1.5) breaks dependents with `< 1.5` bounds;
  relax bounds with `cabal-tweak-dep-ver`, drop deps with `cabal-tweak-drop-dep`, set flags with
  `cabal-tweak-flag` (preferred over patches; § Cabal Flags, Dependencies).
- Bundled extra libraries (`%global subpkgs`, `%ghc_lib_subpackage`) have their **own Version but share the
  main Release**: resetting `Release` without bumping the subpackage version makes its EVR go down.

## Anti-patterns / review points

| Seen | Fix | Level (§) |
| --- | --- | --- |
| Version bump / flag change of a library with no reverse-dep rebuild plan | Rebuild chain (same PR/batch) or don't diverge from Fedora's stack | correctness |
| Diverging one core library from Fedora's Stackage set | Track Fedora; coordinate the whole stack | warning (minimal divergence) |
| Hand-edited `BuildRequires` block between `# Begin/End cabal-rpm deps` | Regenerate with `cabal-rpm refresh`; or tweak the `.cabal` file | SHOULD (Dependencies) |
| Patching `.cabal` for flags/bounds | `cabal-tweak-flag` / `cabal-tweak-dep-ver` | SHOULD (Cabal Flags) |
| Missing `-prof`/static libs in `-devel` | Keep the generated layout (`%ghc_lib_build`, `%ghc_lib_install`) | SHOULD (Shared and static library linking) |
| `Release:` reset while `subpkgs` versions unchanged | Keep incrementing Release | correctness |

Not a finding: rpmlint `undefined-non-weak-symbol` on GHC shared libs (expected per the guideline).

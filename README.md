# Azure Linux repo snapshot timestamps (3.0)

This branch publishes the `tdnf` repo-snapshot timestamps for the Azure Linux
3.0 release stream. Each file under
[`release-repo-snapshot/releases/`](release-repo-snapshot/releases/) corresponds
to one official 3.0 release tag.

For the snapshot file format and how `tdnf` consumes the timestamp, see
[`release-repo-snapshot/README.md`](release-repo-snapshot/README.md).

For Azure Linux source code, build instructions, releases, and issue tracking,
see the main repository: <https://github.com/microsoft/azurelinux>.
